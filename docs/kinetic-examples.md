# Kinetic reel prompts

These briefs use the public `reel` tool through Claude Code. Each produces a new editable
12-second film at 1080p and 60 fps, original percussion, and a rendered storyboard. They are
illustrative brand graphics, not official campaigns or captured product interfaces.

Start a fresh Claude Code conversation after updating the MCP server so it loads `reel`.
Append an absolute output directory and ask the agent to review the storyboard before delivery.
The system supplies the same scene vocabulary and rendering path; creative plans vary by run.

## Linear

> Make a 12-second artistic brand reel for Linear (linear.app). Precision becoming momentum. Orbital paths snap into alignment, huge tightly tracked type, a flood of tiny tasks resolving to one decisive path. Restrained violet on near-black; sharp editorial crops, line-work and extreme scale changes. Words: Focus, Align, Move, Ship. Build a visual arc, not a feature list. Use reel, with palette #101014, #8b7bff, #eeedf5 (dark, accent, paper). Mix bursts and clear holds. Review the rendered storyboard.

## Reference language

The Cloudflare launch film shared by the user transforms identity into type, workflow diagrams
and spatial systems. Its energy comes from controlled changes of scale and graphic relationships,
with rests between bursts. These examples use that general motion language with independently
authored geometry and synthesized audio. They do not use the reference footage or soundtrack.
