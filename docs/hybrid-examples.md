# Hybrid film prompts

These use the public `reel` tool in `hybrid` mode: actual website captures appear inside
authored motion graphics. Pass a captured projectId to reuse your project, or a URL to
capture automatically. Each run creates a separate editable film.

The gallery examples reuse existing captures or discover published product previews, render at 1080p and 60 fps, and carry original
percussion. The model receives a contact sheet. Existing source limitations can remain;
captured pixels are flattened inside the graphic scenes. Plans vary between runs.

## Linear

> Make a 16-second hybrid brand film for Linear from https://linear.app. Use reel with mode hybrid. Mix real captured website visuals with kinetic typography and authored graphics in one film. Precision becoming momentum. Orbital paths snap into alignment, huge tightly tracked type, a flood of tiny tasks resolving to one decisive path. Restrained violet on near-black; sharp editorial crops, line-work and extreme scale changes. Words: Focus, Align, Move, Ship. Build a visual arc, not a feature list. Use four or five product reveal/detail/split scenes between graphic bursts. Give the product room to read. Palette: #101014, #8b7bff, #eeedf5. Prefer product UI and feature artwork over customer photographs. Review the storyboard and source contact sheet.
